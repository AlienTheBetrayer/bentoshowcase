
# 3D Bento Grid
A compact 3D exploration space built around interactive geometry, smooth transitions, and a visually cohesive Bento-inspired layout. This project highlights both the technical architecture behind the grid system and the creative motion design that brings it to life.
![Home Page](https://raw.githubusercontent.com/AlienTheBetrayer/bentoshowcase/refs/heads/main/readme/preview1.png)

## 🚀 Tech Stack
- TypeScript  
- React  
- HTML  
- CSS  

## 📚 Libraries / Additional
- Zustand  
- Three.js  
- Framer Motion  
- GSAP  

## 🧠 Engineering Principles
This project is developed with a focus on clarity, modularity, and responsiveness. State is managed cleanly through predictable data structures, rendering work is isolated for performance, and interactions are built to feel intuitive and lightweight. The goal is to maintain a system that is easy to extend while ensuring consistent and fluid behavior across all user scenarios.

## 📸 Project Overview

### 1. Bento Grid
![Bento Grid](https://raw.githubusercontent.com/AlienTheBetrayer/bentoshowcase/refs/heads/main/readme/preview2.png)
A fully interactive 3D Bento grid built with a structured architectural approach. Each block is rendered in real-time, responds to user input, and forms the core spatial layout of the interface.

### 2. Grid Selection
![Grid Selection](https://raw.githubusercontent.com/AlienTheBetrayer/bentoshowcase/refs/heads/main/readme/preview3.png)
Selecting a grid item reveals its associated content through a smooth animated transition. This interaction shows how information is layered within the 3D space while maintaining clarity and focus.

### 3. Used stack & libraries
![Used stack and libraries](https://raw.githubusercontent.com/AlienTheBetrayer/bentoshowcase/refs/heads/main/readme/preview4.png)
